## 2. 触发规则 (TRIGGER)

此 Skill 在以下输入文档或事件被提交时激活：

- **文档类型**：
  - 科技型企业贷款申请（含线上申请记录）
  - 客户营销记录（含客户访谈纪要、CRM 客户清单）
  - 贷后检查报告（含监控预警、现场检查记录）
  - 不良贷款案例复盘报告
- **关键信号词**（文档内容或标题中包含以下任一）：
  - `科技型企业`、`高新技术企业`、`专精特新`、`科技型中小企业`、`瞪羚企业`、`科技小巨人`
  - `普惠贷款`、`信用快贷`、`科创版`、`善新贷`、`善营贷`、`科技税贷`
  - `科创资质`、`知识产权`、`研发投入`、`纳税`、`经营数据`
  - `客户筛选`、`营销触达`、`贷后监控`、`风险归因`
- **排除条件**：
  - 输入文档明确标记为“非科技型企业”或“传统行业贷款”
  - 输入文档为纯制度原文且无任何业务场景描述（如仅包含法规条文）

## 3. 知识匹配引擎 (MATCHING)

以下 SQL 查询用于从 `golden_items` 和 `golden_documents` 表中匹配知识条目。所有查询均引用真实列名。

### 查询 1：按环节匹配操作流程
```sql
-- 匹配客户筛选或准入校验环节的知识
SELECT gi.*, gd.filename AS source_document
FROM golden_items gi
LEFT JOIN golden_documents gd ON gi.document_id = gd.id
WHERE gi.环节 IN ('客户筛选', '客户数据匹配')
  AND (gi.具体方法 LIKE '%筛选%' OR gi.具体方法 LIKE '%准入%' OR gi.判断逻辑 LIKE '%准入%');
```

### 查询 2：按产品名称匹配产品知识
```sql
-- 匹配信用快贷（科创版）、善新贷、善营贷等产品知识
SELECT gi.*, gd.filename AS source_document
FROM golden_items gi
LEFT JOIN golden_documents gd ON gi.document_id = gd.id
WHERE gi.知识类型 = '产品知识'
  AND (gi.具体方法 LIKE '%信用快贷%' OR gi.具体方法 LIKE '%善新贷%' OR gi.具体方法 LIKE '%善营贷%' OR gi.具体方法 LIKE '%科技税贷%');
```

### 查询 3：按反模式匹配风险控制知识
```sql
-- 匹配包含“反模式”或“踩坑”提示的风险控制知识
SELECT gi.*, gd.filename AS source_document
FROM golden_items gi
LEFT JOIN golden_documents gd ON gi.document_id = gd.id
WHERE gi.反模式踩坑提示 IS NOT NULL AND gi.反模式踩坑提示 != '';
```

### 查询 4：按适用条件匹配营销策略
```sql
-- 匹配无融资需求或产品不匹配客户的营销策略
SELECT gi.*, gd.filename AS source_document
FROM golden_items gi
LEFT JOIN golden_documents gd ON gi.document_id = gd.id
WHERE gi.知识类型 = '营销策略'
  AND (gi.适用条件 LIKE '%无融资需求%' OR gi.适用条件 LIKE '%产品不匹配%' OR gi.适用条件 LIKE '%未触达%');
```

### 查询 5：按来源文档匹配完整知识链
```sql
-- 匹配特定来源文档下的所有知识条目
SELECT gi.*, gd.filename AS source_document
FROM golden_items gi
LEFT JOIN golden_documents gd ON gi.document_id = gd.id
WHERE gd.filename = '科技型企业普惠贷款营销知识文档'
ORDER BY gi.环节, gi.id;
```

## 4. 决策链 (DECISION_FLOW)

按环节组织决策步骤，每步引用 `golden_items` 中的知识条目。

### 步骤 1：客户筛选
- **输入条件**：CRM 客户清单或营销人员输入的客户列表。
- **匹配的知识条目引用**：
  - `KN-001`（环节：客户筛选，具体方法：筛选归属当前网点、账户正常、具备科技标签且未办理普惠信用快贷的无贷户）
  - 知识条目：`核心准入客群优先营销...`（客群筛选）
- **输出判断/建议**：
  - 输出符合筛选条件的客户清单（科技型无贷户清单）。
  - 标记不符合条件的客户及其原因（如无科技标签、已办理信用快贷）。
- **下一跳步骤**：步骤 2（客户数据匹配）。

### 步骤 2：客户数据匹配（准入校验）
- **输入条件**：步骤 1 输出的客户清单。
- **匹配的知识条目引用**：
  - `KN-002`（环节：客户数据匹配，具体方法：校验企业准入条件：成立年限、实控人年龄、征信、纳税/流水/经营稳定、无多头借贷）
  - 知识条目：`信用快贷（科创版）额度10万-500万...`（产品知识，含准入条件）
  - 知识条目：`科技税贷/善营贷依据纳税、开票数据...`（产品知识，含准入条件）
- **输出判断/建议**：
  - 输出符合准入条件的客户清单（准入通过）。
  - 输出不符合条件的客户及其原因（如征信不良、经营数据不稳定、多头借贷）。
- **下一跳步骤**：步骤 3（原因归因与决策建议）。

### 步骤 3：原因归因与决策建议
- **输入条件**：步骤 2 中未通过准入或未办理贷款的客户。
- **匹配的知识条目引用**：
  - 知识条目：`原因归因将客户分为三类：无融资需求、有意但不符合条件、产品不匹配/未触达`（营销流程）
  - 知识条目：`无融资需求客户营销方向为结算、现金池...`（营销策略）
  - 知识条目：`产品不匹配/未触达客户策略：深度访谈...`（营销策略）
  - 知识条目：`风险提示与营销禁忌...`（风险控制）
- **输出判断/建议**：
  - **无融资需求**：建议转向结算、理财服务，定期回访（每季度一次）。
  - **有意但不符合条件**：建议补充资料、改善经营或等待条件成熟，记录跟进计划。
  - **产品不匹配/未触达**：建议深度访谈，推荐善新贷、知识产权质押贷、抵押快贷、税贷等替代产品。
- **下一跳步骤**：结束或进入贷后管理流程（如贷款已发放）。

### 步骤 4：贷后监控与风险归因（扩展环节）
- **输入条件**：贷后检查报告、监控预警数据或不良贷款案例。
- **匹配的知识条目引用**：
  - 知识条目：`风险提示与营销禁忌...`（风险控制，含空壳、无经营、异常征信等风险信号）
  - 知识条目：`科技企业核心痛点...`（痛点分析，可用于风险归因）
- **输出判断/建议**：
  - 识别风险信号（如经营异常、征信恶化、知识产权失效）。
  - 输出风险归因分析（如研发投入过大导致现金流断裂、市场变化导致回款周期延长）。
  - 建议动作：降额、追加担保、提前收回贷款、启动不良处置流程。
- **下一跳步骤**：结束或进入不良分析流程。

## 6. 使用示例 (EXAMPLE)

### 输入
```json
{
  "document_type": "客户营销记录",
  "content": "客户为某省级专精特新企业，成立3年，纳税评级A级，近12个月纳税额稳定，拥有3项发明专利，未办理我行信用快贷。客户表示目前资金充裕，无融资需求。"
}
```

### 处理流程
1. **触发**：输入文档包含“专精特新”、“信用快贷”、“无融资需求”，激活 Skill。
2. **匹配**：
   - 查询 1（客户筛选）：匹配 `KN-001`，客户符合筛选条件（科技标签、未办理信用快贷）。
   - 查询 2（产品知识）：匹配 `专精特新贷/善新贷` 产品知识。
   - 查询 4（营销策略）：匹配 `无融资需求客户营销方向为结算、现金池...`。
3. **决策**：
   - 步骤 1：客户筛选通过。
   - 步骤 2：客户数据匹配通过（成立满1年、纳税正常、征信良好）。
   - 步骤 3：原因归因 → 无融资需求。
   - 建议：转向结算和理财服务，定期回访（每季度一次），等待需求窗口期。

### 输出
```markdown
## 评估报告

### 1. 匹配到的知识条目列表
| 知识编号 | 置信度 | 匹配依据 |
|----------|--------|----------|
| KN-001   | 高     | 客户具备专精特新标签，未办理信用快贷，符合筛选条件 |
| -        | 高     | 客户为省级专精特新企业，匹配“专精特新贷/善新贷”产品知识 |
| -        | 高     | 客户明确表示无融资需求，匹配“无融资需求客户营销策略” |

### 2. 风险信号汇总
- **反模式/踩坑提示**：无（客户未触发反模式）
- **例外情形**：无
- **缺失信息提示**：客户知识产权证书有效期未提供，建议补充

### 3. 建议动作
- **补充尽调**：建议核实专精特新认定有效期及知识产权证书有效期
- **营销策略**：转向结算、现金池、票据池、资金归集等结算服务，推荐大额存单、结构性存款等理财产品
- **维护策略**：长期跟踪、定期回访（每季度一次）、政策同步、等待需求窗口期

### 4. 缺失信息提示
- 知识产权证书有效期：用于确认客户科创资质是否有效，避免过期证书导致风险
