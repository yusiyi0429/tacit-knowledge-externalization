# 通用知识萃取结构 · 专家经验知识库

## 概述

本 Skill 由隐性知识显性化五步法流水线生成，将确认版 Excel 中的场景锚定与知识列转化为结构化 Markdown。

### 场景名称

对公普惠客户潜力营销

### 场景说明

基于网点存量对公客户，运用行内外科技型企业标签与风险数据，识别具备科技资质但未办理普惠信用快贷的潜在客户。通过“客户筛选→客户数据匹配→原因归因→决策建议”的逐层逻辑，输出分层营销建议与产品推荐，实现精准营销与综合金融服务渗透。

### 子场景一览

- **科技型企业普惠贷款营销**：指建设银行拟运用互联网和移动通信等信息通信技术，基于风险数据和风险模型进行交叉验证和风险管理，线上自动受理贷款申请及开展风险评估，并完成授信审批、合同签订、贷款支付、贷后管理等核心业务环节操作，向符合条件的小微企业法人或非法人组织（按照国家有关规定不得办理银行贷款的主体除外）发放的，用于借款人日常经营周转的信用类流动资金贷款业务。本子场景聚焦网点现有对公客户中，具有科技资质且未申请普惠信用快贷的客户名单及原因，并给出营销建议。
