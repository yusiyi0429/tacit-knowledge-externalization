## 1. 背景与目标

用户希望基于“科技型企业普惠贷款营销访谈提纲模板.xlsx”的 **“营销”sheet**，为 **对公普惠客户潜力营销** 场景构建知识库，并生成可验证的 Skill 产物。

该 sheet 的核心圈客逻辑是 **逐层推进** 的：

1. **客户筛选**：从网点存量客户中圈出科技型、未办理普惠信用快贷的客户。
2. **客户数据匹配**：叠加成立年限、实控人年龄、征信、他行信贷等准入/风险数据字段。
3. **原因归因**：对未办理原因进行分类（无融资需求、不满足准入条件、产品匹配度不足/未深度触达）。
4. **决策建议**：根据归因结果输出差异化营销策略与产品推荐。

**本次变更重点**：

- Step1/Step2 模板表头必须严格对齐“营销”sheet 的 11 列表头。
- 知识萃取条目从 3 条扩充到 **12 条**，每层逻辑拆细。
- 最终产物整理成完整 Agent Skill 目录结构：`SKILL.md` + `scripts/` + `references/` + `assets/`。

---

## 2. 设计决策

### 2.1 选型：按营销 sheet 列结构直接构建 Excel 源文件

**原因**：

- 用户明确要求模板表头与 Excel“营销”sheet 一致。
- 直接提供结构化的 Step2 源文件（pre-extract）可以控制条目数量与字段质量，避免 LLM 分组过粗导致只有 3 条。
- 后续 Step3 对齐、Step4 编译、Step5 验证均基于该文件列结构进行。

**未选方案**：

- **继续沿用通用 21 列 schema**：与用户需求不符。
- **让 LLM 自动从 Markdown 源文档萃取 12 条**：需要大幅调整 extraction prompt，且字段映射不可控；本次先以人工结构化 Excel 保证质量。

### 2.2 场景边界

- **场景名称**：对公普惠客户潜力营销
- **场景说明**：基于网点存量对公客户，识别具备科技资质但未办理普惠信用快贷的潜在客户，通过“客户筛选 → 客户数据匹配 → 原因归因 → 决策建议”逐层输出分层营销建议。
- **子场景**：科技型企业普惠贷款营销
- **子场景说明**：本网点现有的对公客户中，具有科技资质且未申请普惠信用快贷的客户名单及原因，给出营销建议。
- **不纳入范围**：
  - “风险”sheet 的贷后/预警内容。
  - 具体阈值（如 X 年、X 周岁、X 万）保留占位符，由本地配置决定。

## 3. 模板表头设计

Excel 表头严格使用以下 11 列（前 4 列固定，后 7 列为知识内容列）：

| 列名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 场景 | 文本 | 是 | 对公普惠客户潜力营销 |
| 场景说明 | 长文本 | 是 | 场景定义 |
| 子场景 | 文本 | 是 | 科技型企业普惠贷款营销 |
| 子场景说明 | 长文本 | 是 | 子场景定义 |
| 步骤 | 文本 | 是 | 客户筛选 / 客户数据匹配 / 原因归因 / 决策建议 |
| 具体方法 | 长文本 | 是 | 操作方法、数据源、判断要点 |
| 知识引用 | 长文本 | 否 | 专家经验、规章制度出处 |
| 规则引用 | 长文本 | 否 | 可执行的判断规则/公式 |
| 专业术语 | 文本 | 否 | 关键术语 |
| 关键输出-名称 | 文本 | 否 | 输出物名称 |
| 关键输出-描述 | 长文本 | 否 | 输出物描述 |

## 4. 知识条目分层规划（12 条）

| 层级 | 条目数 | 条目名称 |
|---|---|---|
| 客户筛选 | 3 | 网点归属与账户状态判定、科技资质标签判定、未办理普惠信用快贷判定 |
| 客户数据匹配 | 4 | 成立年限校验、实控人年龄与身份校验、征信记录校验、他行信贷合作校验 |
| 原因归因 | 3 | 无融资需求判定、不满足准入条件判定、产品匹配度不足/未深度触达判定 |
| 决策建议 | 2 | 无融资需求客户→结算/投资类产品、产品匹配度不足/不满足准入客户→替代贷款产品或持续培育 |

## 6. 实施与验证流程

1. **构建结构化 Excel**：按 11 列表头填充 12 条知识条目。
2. **新建 pipeline**：在默认 workspace 创建新 pipeline，引用该 Excel 作为 Step2 预萃取文件。
3. **运行 Step3 知识对齐**：生成 `final_*.xlsx` / `skill_draft_v2`。
4. **运行 Step4 智能转化**：生成 `SKILL.md`、`COT.md`、`QA`、manifest。
5. **运行 Step5 验证回放**：使用现有 7 条验证用例运行 replay，检查命中率。
6. **补全 Skill 包**：在 delivery 目录下补充 `scripts/README.md`、`references/README.md`、`assets/README.md`，并将源 Excel 复制到 `assets/`。
