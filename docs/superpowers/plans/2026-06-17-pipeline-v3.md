# 新流水线重构方案

## 目标

将当前 IR v2 中心化流水线改为纯 Markdown 流转 + LLM 智能解析的简化架构。

## 与当前实现的差异

| 维度 | 当前 (IR v2) | 新方案 |
|------|-------------|--------|
| Step2 输出 | IR v2 JSON (4阶段条目) | SKILL.md Markdown |
| Step3 对齐 | IR 双视图编辑规则/SQL | Markdown 编辑器 + 实时预览 |
| Step4 输入 | IR v2 JSON | Step3 修订后的 SKILL.md |
| Step4 流程 | 确定性编译 | LLM 解析 Markdown → QA/COT/agent-skill |
| Step5 结果 | 仅 P/R/F1 报告 | 验证通过 → 生成最终版 agent-skill.zip |

## 新流程

```
Step1: 场景锚定
  输入: 场景名称/内容 + 子场景 + 知识列
  输出: 场景骨架 (Excel模板)
  预览: Luckysheet 在线编辑 + 下载Excel

Step2: 知识萃取
  输入: 知识文档 + 场景骨架 (Step1模板)
  LLM: 按场景骨架结构生成 SKILL.md
  输出: SKILL.md (agent-skill初稿)
  预览: Markdown渲染 + 下载.md + 下载场景骨架

Step3: 知识对齐
  输入: SKILL.md (Step2初稿)
  操作: 专家在线编辑Markdown (含SQL)
  输出: SKILL.md (agent-skill修订稿)
  预览: Markdown渲染 + 下载.md

Step4: 智能转化
  输入: SKILL.md (Step3修订稿)
  LLM: 解析Markdown → 生成 QA对 + 思维链 + agent-skill验证包
  输出: QA.json + COT.md + agent-skill_verify.zip
  预览: QA列表 / COT渲染 / 下载全部产物

Step5: 验证回放
  输入: agent-skill_verify.zip + test_customers测试数据
  执行: 解压zip → 运行 execute.py 对测试数据执行SQL
  验证: 对比 agent-skill输出 vs test_customers期望 → P/R/F1
  通过: 重新打包最终版 agent-skill_final.zip
        (SKILL.md + execute.py + manifest + ir_snapshot + QA + COT)
  未通过: 展示分歧, 专家回Step3修订
  预览: P/R/F1指标 / 分歧列表 / 下载验证报告 / 下载最终版zip
```

## 后端改动

### Step2: 新 prompt + 新路由
- `prompts/step2_generate_skill_md.txt`: LLM 根据场景骨架+知识文档生成 SKILL.md
- `/api/step2/extract`: 上传文档 + 场景信息 → LLM → 返回 SKILL.md
- 去掉 `step2_ir_extract.py` 的 extract_rules/generate_sql
- `skill_ir.py` 的 IR v2 构建函数退位为 Step4 内部格式

### Step3: Markdown 编辑
- `/api/step3/save_md`: 保存修订后的 SKILL.md
- `/api/step3/prev_output`: 返回 Step2 的 SKILL.md 内容（文本，非 IR）
- 去掉 IR 对齐逻辑

### Step4: LLM 解析 Markdown
- `prompts/step4_parse_md_to_qa.txt`: LLM 从 Markdown 提取知识条目生成 QA
- `prompts/step4_parse_md_to_cot.txt`: LLM 生成思维链
- `prompts/step4_build_skill.txt`: LLM 生成 execute.py + manifest + ir_snapshot
- `/api/step4/build_skill`: LLM 解析 SKILL.md → 生成 agent-skill_verify.zip
- `/api/step4/generate_qa`: → QA.json
- `/api/step4/generate_cot`: → COT.md

### Step5: 验证 + 最终打包
- `/api/step5/replay`: 同上（解压zip → 执行 → P/R/F1）
- `/api/step5/finalize`: 验证通过后 → 将 QA + COT 注入 zip → 生成 agent-skill_final.zip

## 前端改动

| Step | 输出区 |
|------|--------|
| Step1 | Luckysheet 预览 + 下载Excel |
| Step2 | Markdown 渲染 + 下载SKILL.md |
| Step3 | Markdown 编辑器(textarea + 实时预览) + 保存/下载按钮 |
| Step4 | QA列表/COT渲染/agent-skill下载链接组 |
| Step5 | P/R/F1指标卡片 + 分歧列表面板 + 下载报告 + 下载最终版zip |

每个 Step 的输入区保留"预览上一节点产物"功能。
